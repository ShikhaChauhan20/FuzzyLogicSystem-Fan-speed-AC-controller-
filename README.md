# Python Dungeon Crawler

An interactive 2D arcade dungeon crawler game built with Python and Pygame. Navigate through the dungeon, dodge the chasing enemy, collect spawning gold treasures, and rack up your score!

## Features
- **Smooth Player Movement:** Navigate freely using W/A/S/D or Arrow keys with boundary collision detection.
- **Dynamic Treasure Spawning:** Collect gold coins that instantly respawn at random locations within the dungeon.
- **Chasing Enemy AI:** A blue enemy block tracks and chases the player's real-time coordinates.
- **Score Tracking:** Live score counter displayed on the screen.

## Requirements
- Python 3.x
- Pygame
